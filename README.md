- صفحه خانه
- اخبار داغ و آخرین اخبار
- صفحه جزئیات خبر
- ساختار اولیه گالری/ویدئو/پروفایل
- GitHub Actions برای ساخت APK

اتصال به Backend و پنل مدیریت، آپلود رسانه و Push Notification.
